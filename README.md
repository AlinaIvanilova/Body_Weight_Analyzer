# Weight Tracker (Ruby)

Проста консольна програма на Ruby для відстеження та аналізу ваги.

Програма дозволяє зберігати записи про вагу, переглядати історію змін, виконувати базовий аналіз даних та будувати графік прогресу.

Цей проєкт створений як навчальна практика для вивчення мови Ruby та базових принципів аналізу даних.

## Можливості програми

* Додавання нового запису ваги
* Перегляд історії змін ваги
* Видалення записів
* Базова статистика:

    * середня вага
    * максимальна вага
    * мінімальна вага
    * зміна ваги з часом
* Побудова графіка прогресу ваги

## Приклад роботи

Меню у консолі:

1. Додати вагу
2. Показати історію

## Встановлення

1. Клонувати репозиторій

```id="install1"
https://github.com/AlinaIvanilova/Body_Weight_Analyzer.git
```

2. Перейти у папку проєкту

```id="install2"
cd Body_Weight_Analyzer
```

3. Запустити програму

```id="install3"
ruby main.rb
```
